Option A - Python (Easiest)
   1. Open Command Prompt / Terminal
   2. Navigate to this folder: cd path/to/portfolio-website
   3. Run: python -m http.server 8000
   4. Open browser: http://localhost:8000

Option B - VS Code Live Server
   1. Install "Live Server" extension
   2. Right-click index.html
   3. Click "Open with Live Server"
   4. Browser opens automatically

Option C - Direct File
   Just double-click index.html in your file explorer

STEP 3: DEPLOY (Choose One - All Free!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option A - Netlify (EASIEST)
   1. Go to netlify.com
   2. Sign up with GitHub or email
   3. Drag and drop this folder onto Netlify
   4. Your site is live in seconds!

Option B - GitHub Pages
   1. Create GitHub account
   2. Create new repository called "portfolio"
   3. Upload files
   4. Go to Settings → Pages
   5. Enable GitHub Pages
   6. Your site is at: https://your-username.github.io/portfolio/

Option C - Vercel
   1. Go to vercel.com
   2. Sign up with GitHub
   3. Import this repository
   4. Click Deploy
   5. Your site is live!
