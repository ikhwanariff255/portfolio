## 🚀 Quick Start (3 Steps)

### Step 1: Run Locally (Pick One)

**Option A - Python (Easiest)**
```bash
# Navigate to portfolio-website folder
cd portfolio-website

# Run local server
python -m http.server 8000

# Open browser: http://localhost:8000
```

**Option B - VS Code (Recommended)**
1. Install "Live Server" extension
2. Right-click `index.html` → "Open with Live Server"
3. Browser opens automatically!

**Option C - Node.js**
```bash
npx http-server -p 8000
```

## 🆘 Troubleshooting Quick Reference

### Site won't load locally
- Make sure Python/Node is installed
- Check you're in correct folder
- Try different port (8001, 3000)
- Restart your terminal

### Styles look broken
- Clear browser cache
- Try different browser
- Check internet connection
- Refresh page

### Links don't work
- Check file names match exactly
- Don't use spaces in file names
- Verify all pages in same folder
- Check case sensitivity (Mac/Linux)

### Can't deploy
- Check Git is installed (for GitHub)
- Verify folder structure is correct
- Try different hosting service
- Check documentation again
